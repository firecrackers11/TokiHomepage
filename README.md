# TokiSystems corporate website

Static corporate website for `tokisystems.io`.

## Publishing

The repository includes a GitHub Pages workflow. Push to `main`, select **GitHub Actions** as the Pages source, verify the custom domain, and enable HTTPS.

Before publishing, create `contact@tokisystems.io` in Google Workspace or replace the address in `index.html`.

## Content note

The site presents TokiSystems as an independent company. Earlier company names are intentionally not used. Experience entries that predate TokiSystems are explicitly presented as the lead engineer's prior work.

Generated concept images are labeled on the site and can be replaced independently under `assets/images/`.
